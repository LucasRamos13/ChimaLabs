## Decisões
- Uma lista de índices aplicada a uma matriz dá uma linha; aplicada a um vetor, segue a orientação dele. Uma máscara lógica aplicada a uma matriz dá uma coluna.
- A atribuição converte o lado direito para a classe do alvo. A prática comum às vezes muda a classe do alvo; aqui ela só muda quando o alvo está vazio ou o valor é complexo, o que é mais previsível.
- Uma máscara mais longa que o array é aceita se o excesso for falso.

## Rigor
- **Proptest:** atribuir e ler devolvem o mesmo valor, crescendo quando preciso.
- **Cobertura:** 99,4% das linhas do crate.
