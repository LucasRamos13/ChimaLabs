## Convenção da API
As funções recebem arrays N-D em ordem column-major como `(dados, forma)` e uma dimensão (a partir de 0), sem depender do modelo de valores do runtime, que ainda será definido (Fase 2). Dimensões além das existentes são tratadas como singleton.

| Capacidade | Estado | API |
|---|---|---|

## Decisões de comportamento
- `ConvShape::Same` com núcleo par: a saída começa no índice `⌊nb/2⌋` da convolução completa.
- `filter` normaliza os coeficientes por `a₀`; `a₀ = 0` é erro `argumentoInvalido`.
- Convolução usa FFT quando `na·nb > 65536` e os dois têm ao menos 32 elementos. O resultado difere do cálculo direto só por arredondamento (≤ 1e-10 no teste com 3000×500).
